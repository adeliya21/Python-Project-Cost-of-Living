# Pyhton-Project-Cost-of-Living

## About the Project

This project analyzes the cost of living across cities worldwide using Python and statistical modeling techniques. The analysis is based on the Global Cost of Living dataset on Kaggle, which contains data collected by scraping Numbeo's website.

The dataset includes 4,873 observations across nearly 5,000 cities and 59 variables. A subset of 11 variables is selected to investigate cost-of-living patterns, explore relationships between economic indicators, and identify the factors most strongly associated with living costs.

## Project Objectives
- Explore global cost-of-living patterns through data analysis and visualization.
- Investigate relationships between cost-of-living indicators.
- Test statistical hypotheses to evaluate relationships and differences between variables.
- Build regression models to identify key predictors of cost-of-living indicators.

## Methodology
- Data Cleaning & Preparation: Filter, clean, and transform the dataset for analysis.
- Exploratory Data Analysis (EDA): Examine distributions, trends, and relationships using Seaborn visualizations.
- Hypothesis Testing: Apply t-tests to assess statistically significant differences between groups.
- Statistical Analysis: Use linear regression to investigate relationships between variables.
- Predictive Modeling: Compare Multiple Linear Regression, Ridge Regression, and Lasso Regression to evaluate predictive performance and identify influential features.
